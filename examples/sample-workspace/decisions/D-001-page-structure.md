# Decision D-001 — landing-page structure

**Date:** 2026-01-10  
**Status:** ACCEPTED  
**Decision authority:** Human owner  
**Project state examined:** `PROJECT.md` and the Research report dated 2026-01-10

## Question

Should the page begin with the full repository map or guide the reader through a smaller entry path first?

## Evidence

- Research report: `roles/research/reports/2026-01-10-onboarding-structure.md`.

## Decision

Use promise → path selector → lifecycle → repository map → limitations.

## Consequences

- The first viewport stays focused on reader value.
- Detailed navigation remains available below the lifecycle.
- The Task Contract must preserve this order.

## Revisit when

Reader testing shows that the selector delays rather than improves discovery.
