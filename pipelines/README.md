# Pipelines

Pipelines are optional flows selected by output type. They are independent of the four Levels.

- [Standard task](standard-task.md) — bounded work from intent through memory update.
- [Research](research.md) — external knowledge into a sourced project report.
- [Domain role](domain-role.md) — recurring research into owned knowledge and report contracts.
- [Visual assets](visual-assets.md) — brief, generation, curation, approval, normalization, and indexing.
- [Mock to implementation](mock-to-implementation.md) — reference render, layout data, implementation capture, comparison, and approval.

For example, a visual task may use the Mock-to-Implementation pipeline under Level 2, 3, or 4. The Level defines coordination and authority; the pipeline defines how that output is produced and verified.
