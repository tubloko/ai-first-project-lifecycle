# Levels

Levels are complete operating configurations. They are not sequential lessons and do not label an entire project permanently.

| Level | Use when | Core loop |
|---|---|---|
| [1 — Focused Session](1-focused-session.md) | one session can safely finish and inspect the work | Brief → Work → Verify → Result |
| [2 — Resumable Project](2-resumable-project.md) | state must survive sessions or models | State → Work → Verify → Update state |
| [3 — Separated Lifecycle](3-separated-lifecycle.md) | planning, execution, and review need distinct contexts | Brain → Contract → Executor → Evidence → Review |
| [4 — Governed Autonomy](4-governed-autonomy.md) | a reliable Level 3 loop should repeat across bounded tasks | Orchestrate → Execute → Gate → Update → Repeat |

Use [Choosing a level](../docs/choosing-a-level.md) before adopting one.
